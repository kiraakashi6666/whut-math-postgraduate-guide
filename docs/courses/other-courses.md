# 其他核心课程经验

## 大学物理A 上下(3.5+3.5) + 物理实验A上下(1+1)=9
    **44同学强烈建议**：我们这一届的修读计划是大物A上下，好像接下来几届就都是大物B了，难度稍低，根据**风评选个好老师**，平常上课认真听老师讲就好了，**老师PPT上的练习题、大物教材以及配套习题册是复习重中之重的资料，甚至可以看成题库**，因为把这些题搞懂搞透甚至举一反三期末考试不成问题，另外注意大物实验要好好做，最好是选到前半学期做，后半学期做就会容易下午做实验晚上考期末考试。
    
## 概率论与数理统计A 4.5
    
    这个课是比较简单的专业课了，重计算（不是没有证明啊），平时基本没啥作业，自己期末练一下各种题型（我看的茆书习题，难度是高于期末的）就行。
    
    pk老师(数学系应该都是)请**尽力把他期末考试前发在群里的word文档仔细观看**，他上课出的题目也尽量全记下来，不然期末等待的将会是迎头痛击。
    
    网课可以看**B站一高数**。
    
## 数值分析D 3
    
    看**网课B站划水的赛宝儿**，基本覆盖所有题型了。反正上课我没听懂，老师期末不发真题卷（说发了就要提高考卷难度，确实最后考的很简单）。
    
## 复变函数A 3
    
    选的hzy老师的课，讲的很清楚的，不需要看课，**板书记一下**。平时课本例题和课后习题完成就可以应付期末考了。
    
## 数学物理方程A 2.5
    
    wty老师，平时讲的非常难，一堆不会的证明。考试计算为主（好好做作业），比较简单，99、100不少。不需要看网课。又部分“摘苹果”分时，需要小组一起完成一个证明任务（非常困难用AI）。
    
## 模式识别C 3
    
    wy老师（所有人这位老师），开卷考，平时PPT例题和作业关注下，简答+计算。计算题很好准备，这本书能考计算题的不多；简答题自己需要准备些资料（比如西瓜书）。平时分应该有一部分需要小组展示。
    
## 数据分析 3
    
    wcm老师（所有人都是这位老师），平时老师讲课板书就会点名这个题型很重要，但是这个课程事情很多，很耗精力。平时分有实验报告+小论文（小论文格式要求很高，注意这学期期末你还会有个实践课也是这个老师，要实验+大论文用SPSS，要求也很高，会要求发给她然后给你提意见你要去修改）。期末考要用计算器，题量很大，**老师的期末划重点内容和考纲要很熟悉**（平时也好好记笔记，虽然老师总说期末她不会划重点了她还是划了哈哈）
    
    大家分都不高，90分以上好像是6个还是9个，有同学挂科。
    
## 微分方程数值解
    
    hr老师（所有人都是这位老师），老师讲的挺好的，按照板书+PPT+课本即可。期末考不好说，因为这个课一学期要讲完很赶（如果后面是读计算数学研究生一定要熟悉），划重点了但是不一定考（前车之鉴，惨痛教训），自己多复习一点。
    
## 离散数学B 3
    
    pnn老师（所有人都是这位老师），老师讲的挺好，按照PPT即可（会发群里）。平时黑板板书注意一下，会提醒你记笔记（赶紧记搞不好是原题）。99、100很多，不用担心。
    
## 数据结构与算法B 3
    
    忘了是哪个老师了，应该大家都一样。这个课要转计算机要好好听一下，注意听老师上课就行，期末应该是划重点了（不记得了）。期末考有设计算法题，平时要对什么冒泡、插入这种熟悉。
    
## C程序设计基础A 2
    
    好想是lm老师，刷题即可，很多满绩。
    
## 面向对象程序设计B 3
    
    ljx老师，很和蔼快退休了。划重点的期末重点看即可（概念填空+程序填空，前者他平时会提到这个很重要期末也会再次强调，后者主要是类与对象开始什么继承派生），平时偶尔会点人回答（答不出啥事没有）。
    
## 常微分方程 3 选修
    
    **保研笔面的高频出现课**，课程本身难度不大，反正就是把各个类型的方程求解搞明白，定理比较重要的就是那个解的存在唯一性定理。
    
## 实变函数A 3 选修
    
    gz老师。这课不多说了，根本学不会，B站看**《实变函数》用书是chengqirang等编的书只讲实变部分**这个课。虽然但是**最重要的是期末的两节习题课，建议背出来**。
    
## 机器学习 3 选修
    
    结课是**大作业**，不过往届也有是开卷考的。xl老师（所有人都是这位老师）人特别好，这门课重点其实不在期末拿高分了，因为**保研想转码或者想做深度学习**这种方向的同学，这门课是一定要好好了解学习的，就像前面说的，保研面试专业课其实是会有很大几率被问到的。
    
## 补充：一些课程是会带有上机实验课的，比如MATLAB，数学模型，数据结构，C语言，面向对象(C++)，模式识别，机器学习，数据分析，数值分析等等，要认真完成老师布置的任务，部分课程的课程设计其实可以包装成保研经历写在简历上。

以上就是学分较高的部分课程，经验仅供参考。
