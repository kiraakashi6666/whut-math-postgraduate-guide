# 数学分析课程经验

> 只记录较高学分课程。因为每一门都想拿高分难度非常高，策略就是在高学分的核心课程（保研重视的课程）拿到高分。不必给自己施加太大压力，尽可能把考前工作做好，期末分数七成来自你的努力三成来自运气和老师。
> 
## 数学分析123 (5+6+5 = 16)
    数学分析毫无疑问是所有课程中最为重要的，它的总学分达到了16，对数统学院学生的保研排名至关重要。
    
    依稀记得**大部分考题是课本课后习题+例题的改编**，压轴题很可能是某个定理的证明（我记得大一期中是证明海涅定理，大二数分3是用有限覆盖证明零点存在定理，都是课本定理和例题）。**期末考老师会发往年真题**。
    
    本人数学分析没有看网课，学院老师讲的还不错的。zwr老师教的很好，会分题型讲解，适合应试，但是他平时分不好拿；wz老师平时分基本都是满分（只要交作业），但老师讲课喜欢一点点从定理推，行云流水的，仔细听也是能听懂的。
    
    平时作业讲解看**B站赤小师**。
    
    **44同学补充：**想要备考考研冲名校的，或者说自己对自己要求比较高(真的有吗)，数分可以去看一下裴礼文那本习题，高代绿皮书白皮书，另外老师也有给我们推荐过吉米多维奇习题集。
