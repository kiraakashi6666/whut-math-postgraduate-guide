# 高等代数课程经验

## 高等代数12(4+4=8)
    高等代数学分也很高，这门课对现在深度学习什么理论学习挺有用的。相比数学分析还是比较简单的。
    
    **whut用的是自己的教材（zl和ly老师主编的）**，老师也讲的不错的，不需要额外看课程。作业是打印的配套作业纸，期末考题是类似题型（会举一反三）。
    
    zl老师讲课更应试，也是题型讲解，绝对能听懂，也有作业讲解和**期末习题课（很重要！）**，但是老师比较严格，你的期末考基本就是你的总绩点；ly老师讲解就有时会花很多时间证明（可能不考的），更“随心所欲”一些，需要自己辨别哪些是会考的，老师**期末也是会划重点**不用担心，给分也很好的。
    
    ly老师期末是发了很多年的真题卷，本人是都写了，实际考的题目也有涉及（可能改了下数字什么的）。
