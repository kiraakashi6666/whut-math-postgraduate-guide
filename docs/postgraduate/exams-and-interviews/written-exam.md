# 笔试准备

## 信息搜集与目标确立

相关信息的搜集与目标的确立十分重要，否则就会像无头苍蝇一样乱转，精力分散、浪费时间。
信息来源主要是：学长学姐经验分享（学校组织，可添加学长学姐联系方式自行礼貌询问），xhs、dy等社交平台，各大保研群、公众号等。

- **确认笔试科目**：根据目标学校官网发布的往年信息，以及小红书、抖音等社交平台上的经验分享，尽量确认笔试科目。比如往年东南大学数学的笔试科目就是：实变函数、复变函数、数值分析、常微分方程、近世代数五门。
- **无法精准确认时**：当然也有无法精准确认考试科目的情况，比如东南大学系统科学只说考察人工智能基础，这时就需要自己结合多方信息确认复习的重点科目。
- **获取往年真题**：通过靠谱的渠道获取该校往年笔试卷。结合学长学姐经验与自身经历，想保研数学、统计的同学比较推荐"N次方数学保研小屋"公众号，它确实有一些相关的试题和面试复习资料。

## 复习策略

对于笔试科目较多、且真的是自己梦校的学校，如果结合往届经验确认自己进入复试的可能性较大，尽量给自己留出充足的时间复习，进行充分的准备（系统复习知识点 + 刷往年卷）。这不仅能增加通过的概率，也能增添信心。

## 心态调整

最后讲一点玄幻的东西：有些时候运气也是实力的一部分。如果真的觉得自己时间不够、复习不完，也不用太慌张——也许考场上遇到的就是你复习过的；你不会的，可能大家都不会，最后分数也许并不低。

总之：**尽人事，听天命，平常心。**
