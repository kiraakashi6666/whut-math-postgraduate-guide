# 保研须知

## 保研看什么
以下顺序适用数统学院情况，仅供参考。

1. **绩点排名**：[期末备考](../gpa/final-exam-preparation.md)部分提及了whut使用计算的一些绩点排名。综测排名不被大部分学校认可。注意：如果排名有冲突，比如**同学校同一专业**，小A填写了必修绩点排名第一，小B填写了平均学分绩点排名第一，有概率都不入营（有些学校会写在通知上，比如复旦大学）。
2. **英语**：六级or托雅有隐形/明确门槛，详见各学校通知。自然是越高越好。
3. **竞赛**：数统学院相关专业基本不看竞赛，数模比赛可看，但最看重的是**数学竞赛**（比较出名的几个可以自己搜）。
4. **科研**：数统学院相关专业基本不看科研和论文。

## 如何了解保研信息和经验

1. 保研政策学校官网就有，一定要确认自己加分情况。
2. 学校每年A/B保名单会进行公示，可以联系学长学姐学习经验。
3. 学校每年会举办保研动员会、经验分享会，会邀请到老师讲解、学长学姐分享，可以仔细听。
4. 和老师多交流（班主任、任课老师、辅导员）。数统学院的老师都非常热心，愿意为同学们答疑解惑。尤其是毕业于你意向学校的老师，可以多多交流。
5. 校园集市。校园集市上会有一些学长学姐分享保研的经历，或者自己可以发帖捞捞。
6. xhs。🍠上的经验帖有一定可信度，但是刷多了容易焦虑内耗，不建议多刷。

> 虽然保研有竞争，但是还是可以和同学们交流交流。有时候倾诉倾听很重要，也是信息的来源。
