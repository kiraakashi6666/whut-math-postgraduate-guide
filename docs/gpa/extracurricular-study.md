# 课外学习

## 英语
英语是课外学习不可少的一部分。保研的部分学校对于六级分数是有要求的，同时英语好的同学老师也会比较喜欢。

笔者们六级均在550以上，平时碎片化英语学习必不可少：
1. **背单词**。至少六级考试之前的1-2个月必须天天背！每天一般背30-50个差不多，背单词不一定让你记住，主要是逼自己养成学英语的习惯（虽然笔者们考完四六级雅思就不背了）。
2. **听听力**。听力建议四六级考前1个月开始每天练一套题，四六级听力重要性不用多说了。没有什么技巧其实，就是熟能生巧。平时也可以看美剧英剧替代红果这些（有一说一AI漫剧确实容易上瘾）。
3. **刷真题**。四六级考前1个月开始每天刷真题，可以只刷某一部分（比较大一大二课也挺多的），周末一定一定要完成一套真题卷，给自己规定时间完成然后批改，作文让AI批改就行（然后可以让它帮你修改，积累自己的语料素材库）。

> 后续如果想了解雅思备考的，笔者可以进一步更新。

## 怎么找课
大学里有一些课程光靠课堂那些，其实很难听懂和掌握。尤其是部分课程期末考和平时课程内容相差极大。所以必须要学会在平台上自己找课看。

找课一般有两个来源：

- **B站**
    
    B站绝对是最主要的找课平台。一般可以看一下合集大纲、课本和你课上用的是否一样；同时可以听一下看自己是否适应；也可以和同学交流讨论下。还有个笨办法：让AI给你推荐。不过通常来说，播放量高、收藏人数高的课程质量会好一些。
    
- **慕课**
    
    这个有，但是用的还是比较少。部分同学有看这个的，但主要还是在B站看。
