# 日常学习

大学的学习和过往高中的题海战术略有不同。首先，大学老师上课风格迥异，不一定都能适应（开小差、听不懂、跟不上很正常），老师们也不会像高中老师那样追着你学；同时课程时间较长，WHUT数统学院本科生培养方案课程3小节的较多（3个45分钟中间2次5分钟课间休息），一个人的专注时长是有限的，不可避免会遗漏一些内容。因此在大学期间更强调**自主学习能力**。

以下内容是笔者们总结的一些经验，供大家参考。

## 听课
很多同学可能会说大学听课没有用，但是以**保研为目标**、**数统学院**的学生还是强烈建议要听一下。具体原因会在后面提到。

### 笔记
> 仅供参考，笔记本或者纸质记录也有用得好的！
- **选用工具**：平板
    -  数统这边很多课的书非常厚，不方便携带。
    -  部分老师习惯按照自己PPT讲，上课才会发PPT在QQ群/小雅【待添加链接】，平板就可以马上打开标注。
    - 期末复习时有妙用（详见【待添加链接】）。
- **为什么强烈建议记笔记**：
    - 部分老师在讲到某些知识点时，会提及 **“请同学们记下来”** 、**“期末考我们会考察类似题型”** 等，这些很可能是**期末考**需要考察的，平时记下来期末便于复习考点。
    - 部分老师不常写板书，但**当ta突然开始写时，特别是一些例题**，请你赶紧记下来，相关的内容有一定概率要考。当然有少部分全程板书的老师（似乎每个知识点都要考），谁知道ta写的考不考呢，记下来也不花什么力气（别想着期末找同学要，自己记全更放心）。
    - **习题课和期末的最后几节课一定要注意里高度集中**。习题课的题目很可能是你期末考的变形，必须记下来并掌握；最后几节课很可能要划重点/讲考试大纲了，一定一定要仔细听。
- **怎么记笔记**：
    一般是用平板上的笔记软件记（如 Notein），可以将电子书、PDF在软件打开并进行批注。假设老师并没有发PPT，可以开一个分屏打开**小雅** 【链接】看有没有或者打开**智慧理工大 > 智播课堂** 截取PPT。
> 部分教室智播课堂用不了，只能拍照了！

不同的课程还是有一定差别，上述总结的经验对于笔者们非常有用。当然不乏有一些**天才同学**，全靠期末突击得到不错的分数，但是**数统学院**部分专业课不容小觑，有的速成拿不到高分（比如学分极高的**数学分析**【链接】，笔者之一经过第一学期惨痛教训，通过平时积累，最终拿到将近满绩）。

### 关于要不要认真听课
笔者们还是比较认真地去听，周末也会补听（智播课堂）。虽然老师不一定能教得会，笔者们课外也会自学，但有时候老师的教学提示都是有意味的。不要总是寄希望于期末考试大纲，部分课程**没有**！

可能还是有的同学不想听，有自己的学习节奏，笔者们也表示尊重，唯一提醒：**请把考勤分拿到，作业按时完成提交，平时分拿满！** 
> 然而事实是认真听课的同学都在**专业前列**！
