# 期末考试：选课

**大学想要在期末考考高分，请你“抛弃”高中时期的学习方式**。Whut 数统这边的课程在教学安排、考核方式和复习重点上各有不同，选课前可以先了解课程信息，再结合自己的学习节奏作出选择。

**选课对学习体验和成绩会有一定影响，但不是决定性因素。**

## 如何了解课程信息？

- **问学长学姐**
    
    直系学长学姐通常了解课程安排与考核方式。可以通过社团、活动或校园社区联系，多参考几位同学的经验。
    
- **校园集市**
    
    校园集市有课程评价板块，可以用来了解课程内容、作业量和考核方式。评价带有个人主观感受，建议结合培养方案和课程通知综合判断。
    

![校园集市课程评价入口](../assets/campus-course-review.png)

## 万一抢课抢不到…

抢不到热门课程也很正常。选课会影响学习体验，但**更关键的是平时投入和期末准备**。可以做好以下三点：

- **放平心态**。一门课对整体绩点的影响有限，不必因为没有选到第一志愿课程而过度焦虑。
- **完成平时任务**。及时完成作业、课堂测验和课程要求，具体见[听课与笔记](classes-and-notes.md)。
- **认真准备期末考试**。提前确认考核比例与考试要求，再按计划复习，具体见[期末复习](final-review.md)。

尽可能把过程做好，也给结果保留一点弹性。
