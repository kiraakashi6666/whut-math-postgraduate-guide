# 引言

《WHUT 数学er 学习指南》由两位大四学姐共同整理。我们希望把自己在大学期间积累的一些经验分享给学弟学妹，让大家在遇到相似的问题时，能够少走一些弯路。

回想过去的大学生活，很多时刻我们都希望有人能帮忙答疑解惑：初入校园时，我们不知道快递站在哪、图书馆怎么进、电瓶车哪里充电；开始学习时，我们不清楚大学应该怎么学、该如何准备期末考；决定争取保研时，我们不了解保研要怎么规划、预推免怎么准备笔面...... 无论是学习还是生活，我们都曾遇到过各种各样的问题。那时的我们不知道应该去哪里寻找答案，只能一点点试错、收集信息，再慢慢总结出自己的经验。

如今，本科生活转眼接近尾声。我们希望把这些经验和教训整理成这份指南，传递给之后的学弟学妹。它不一定适用于每一个人，但如果其中的某些内容能够为你提供一点帮助，这份指南就有了意义。
